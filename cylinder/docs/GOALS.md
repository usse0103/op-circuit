# 油圧シリンダー設計（hydraulics/cylinder） 最終目標

油圧シリンダーの設計を「毎回スペックを決める作業」から「条件を入れれば標準と計算で決まり、例外だけ人が直す作業」に変える。
新品の設計と、修理物（規格外を含む）の図面化・強度確認の両方を 1 つのツールで扱う。

- 利用者: 自分だけ（このPCで使う）
- 最終的な図面の仕上げ（寸法・注記）は IJCAD で行う

## 1. 扱う範囲

| 項目 | 内容 |
|---|---|
| 形式 | タイロッド形、溶接形（丸形） |
| 取付形式 | 選択式（例: クレビス、トラニオン、フランジ、フート。対応する種類は §8 で決める） |
| クッション | あり／なしを選べる |
| 圧力 | 標準系列 7 / 14 / 21 MPa から選ぶか、任意の値を入れる |
| 新品／修理 | 両方 |

## 2. 入力の仕方（2 つのモード）

### A. 新品モード

次のどちらからでも始められる。

1. **推力・圧力・ストロークから**: 必要な推力（押し・引き）と使用圧力から、ボア径を系列の中から自動で選ぶ
2. **ボア径・圧力・ストロークから**: 径は自分で決め、それ以外を自動で決める

自動で決めるもの（すべて画面で上書きできる。上書きした項目は分かるように表示する）:

- ロッド径（座屈・推力比から）
- チューブ外径・肉厚
- カバー寸法（角寸法・長さ）、タイロッド径・本数・ピッチ・締付トルク
- ポートサイズ（流量・速度から、または系列から）
- ロッド先端ねじ、ピストンナット
- シール一式（溝寸法と型式）
- 材質

### B. 修理モード

- 現物の**実測寸法**を入れて、部品図・組立図を出す
- 実測寸法と使用圧力で**強度チェック**（足りないところを判定して表示）
- **一部の部品だけ**図面化できる（ロッドだけ、チューブだけ、など）
- 既存の溝寸法に合う**シールの代替品**を探す
- 海外製シールの場合は、シールもハウジング（溝）も採寸寸法で扱う

## 3. 寸法を決める根拠

優先順位は「上書き > 社内標準 > 規格 > 強度計算で求めた最小値」。どれで決まったかを画面と計算書に残す。

- **規格**: 国内メーカーの慣例（7/14 MPa タイロッド形でよく使われる JIS B 8354 系の寸法）を基準にする。
  ねじ・Oリング溝などは JIS。系列に無いサイズや他系列（ISO 6020 系＝JIS B 8367 など）は例外として扱えるようにする
  （系列表に行を足す／その案件だけ上書き、のどちらでも）
- **強度計算**: 規格・標準で決めた寸法が足りているかを必ず確認する。規格外（修理物）は計算だけで判定する
- **社内標準**: 柔軟に変えられるように、コードではなくデータ（Excel）で持つ

### 社内標準データの管理

```
hydraulics/cylinder/standards/
├─ standards.xlsx        社内標準（寸法表・安全率・材質・系列など）。ツールはここを読む
└─ sources/              規格・カタログの PDF をそのまま入れる受け口
```

- 自分で編集するのは `standards.xlsx` だけ
- ネット上のカタログや規格の PDF は `sources/` に入れておけば、Claude が読んで `standards.xlsx` にまとめる（出典のファイル名とページを残す）
- ツールは起動時に `standards.xlsx` を読み込む。値を変えたらすぐ反映される

## 4. 強度計算

安全率は**引張強さ基準**（許容応力 = 引張強さ ÷ 安全率）で、**部位ごとに設定で変えられる**（`standards.xlsx` で管理）。

| 安全率の初期値 | 値 |
|---|---|
| 内圧を受ける部品（チューブ・カバー・タイロッド・ねじ・溶接部・取付部） | 4 |
| ロッドの座屈 | 3.5 |

計算する項目:

| 部位 | 内容 |
|---|---|
| チューブ | 内圧による周方向応力（厚肉円筒）、肉厚の判定 |
| ロッド | 座屈（取付形式と伸び切り時の長さから）、引張・圧縮 |
| ロッド先端ねじ | 引張・せん断 |
| ピストン取付部 | ナット・ねじの強度 |
| タイロッド | 内圧による引張、必要な締付力 |
| カバー | 内圧による曲げ（必要な厚さ） |
| 溶接部（溶接形） | 溶接部の応力 |
| 取付部 | ピン・クレビス・トラニオンのせん断・面圧 |

あわせて出すもの: 推力（押し／引き）、速度・必要流量（流量を入れた場合）、重量。

### 標準材質（初期値。`standards.xlsx` で変えられる）

| 部品 | 材質 |
|---|---|
| チューブ | STKM13C（ホーニング） |
| ロッド | S45C 高周波焼入れ＋硬質クロムめっき |
| カバー（ヘッド・ロッド） | S45C |
| ピストン | FC250 |
| タイロッド | SCM435 |

## 5. シール

- 溝寸法は JIS をベースに決める
- 可能なら NOK の型式も自動で出す（ピストンシール、ロッドシール、ダストシール、ウェアリング、Oリング、バックアップリング）
- 修理モードでは、既存の溝寸法から合う型式を逆引きする
- 海外製シールは型式の自動選定はせず、採寸したシール寸法と溝寸法をそのまま図面と部品表に載せる

## 6. 成果物

| 成果物 | 形式 | 状態 |
|---|---|---|
| 部品図（寸法・注記なしの投影図） | DXF | ✅ 済み |
| 組立図 | DXF / PDF | ✅ 済み（寸法は全長・角寸法のみ） |
| 強度計算書 | PDF（提出用）と Excel（数値の確認・手直し用） | 未着手 |
| 部品表・購入品リスト | CSV / Excel（シール・ナット・ブッシュ等の型式まで） | 部品表のみ済み。購入品は未着手 |

## 7. 進め方（マイルストーン）

1. **M1 新品の自動選定** ← 最初にやる
   - `standards/` の仕組みを作り、まずはタイロッド形・取付なし・クッションなしで、条件 → 全寸法を自動で決める
   - 推力からボア径を選ぶ／ボア径を指定する、の 2 通り
   - 決まった寸法の根拠（規格／社内標準／計算／上書き）を画面に出す
2. **M2 強度計算書**: §4 の項目を計算し、PDF と Excel に出す。M1 の自動選定のチェックにも使う
3. **M3 シール選定**: 溝寸法の自動決定と NOK 型式、購入品リスト
4. **M4 修理モード**: 実測寸法の入力、部品単位の図面化、強度チェック、シールの逆引き
5. **M5 形式の追加**: 溶接形、取付形式、クッション
