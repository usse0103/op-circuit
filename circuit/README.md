# 油圧回路設計（hydraulics/circuit）

油圧回路をドラッグ操作で描き、流量・圧力・発熱を計算して図面に書き込む。
全体計画は [../../MASTER_PLAN.md](../../MASTER_PLAN.md) の P3（油圧回路）。

- 図記号は JIS B 0125-1984。機器の記号は 2.5 mm の格子に乗り、用紙（A4・A3・A2 横）にそのままの寸法で刷れる
- 計算は工程ごと（電磁弁の位置、シリンダの移動・停止）に行い、1 サイクルの平均発熱と油温を見積もる
- 積層弁（モジュラー弁）は、P・T・B・A の 4 本線に機能を並べたスタックとして扱い、積層順序の誤りを警告する

## 起動

`start.bat` をダブルクリックする（初回は `.venv` を作って Flask と numpy を入れる）。
ブラウザで <http://127.0.0.1:5010> が開く。止めるときは「hydraulics-circuit」のウィンドウを閉じる。

WORK CONTROL PANEL（`projects/work-control-panel`）の上部、`BACKUP` の右の `CIRCUIT` ボタンからも起動できる
（パネルが `start.bat` を `HC_NO_BROWSER=1` 付きで実行し、タブはパネル側で開く）。

手で起動するとき:

```bash
.venv\Scripts\python.exe app.py 5010
```

## 使い方

| したいこと | 操作 |
|---|---|
| 機器を置く | 左の一覧からドラッグ。クリックしてからキャンバスをクリックでも置ける |
| 配管する | ポートの丸からドラッグして、相手のポートか配管の上で離す（配管の上なら分岐点ができる） |
| 経路を直す | 配管の中間の線分をドラッグ。配管をダブルクリックすると分岐点が入る |
| 弁の位置を変える | 弁をダブルクリック、または下の「工程表」で選ぶ |
| 数値を入れる | 右ペインのスライダー、数値欄（式を書ける）、電卓ボタン（面積・単位換算） |
| 回す・反転 | R・F。矢印キーで 2.5 mm ずつ動く |
| 囲む・注記 | 上のバーの包囲線（一点鎖線）と文字 |
| 印刷 | 「印刷」。1 ページ目が図面、続けて計算書（A4 縦）。SVG でも保存できる |

回路は変更のたびに `data/circuits/<id>.json` に自動で保存される。削除したものは `data/trash/` に移る。

## 機器を足す

1. `library/*.json` に定義を足す。`params` に書いた項目が、そのまま右ペインの入力欄になる
   （`min` `max` `step` がスライダーの範囲、`type` が `select` `bool` `text` なら選択・スイッチ・文字）
2. 図記号が要るときは `static/js/symbols.js` に `gen('名前', (p, ctx) => …)` を足し、定義の `symbol` に名前を書く
3. 計算モデルが要るときは `hc/models.py` に `@model('名前')` の関数を足し、定義の `model` に名前を書く。
   既存の要素（`Orifice` `Check` `Relief` `Reducing` `Sequence` `FlowControl` `PilotCheck` など）を
   端子につなぐだけで作れる

カタログの弁を登録するときは、既存の機器を写して `q_rated`（基準流量）と `dp_rated`（その流量での圧力損失）を
カタログの圧力損失線図の値に変える。初期値は代表値で、実機の値ではない。

## 計算のしかた

- 回路を「節点（同じ圧力の点）」と「要素（節点の間に流量を流すもの）」に分け、各節点で流量の和が 0 になる圧力を
  減衰つきニュートン法で求める（`hc/network.py`）
- 機器の圧力損失は ΔP = ΔP0·(Q/Q0)²、絞りは Q = 60·k·A·√(2ΔP/ρ)、配管は層流 λ = 64/Re、乱流 λ = 0.3164·Re^(-1/4)
- リリーフ弁は、クラッキング圧力から開き、調整時流量で設定圧力になる直線の特性
- シリンダは、流体力が負荷を超えると動く。速度は流量で決まる。「停止」にするとストロークエンドとして扱う
- 発熱は、軸入力から機械的な仕事を引いた残り。要素ごとに ΔP·Q/60 [kW] を積み上げる
- 油温は T = Ta + (H − Hc)/(k·A)。放熱面積 A は入力するか、油量から A ≈ 0.065·V^(2/3) で見積もる

定常計算なので、切換時のサージ圧力、アキュムレータの充填・放出、慣性による加減速は扱わない。

## 確認

```bash
.venv\Scripts\python.exe tests\test_engine.py
```

手計算できる回路（全量リリーフ、シリンダの伸び、過負荷、配管の圧力損失）と、積層弁の回路で答えを照合する。
