# hydraulics（油圧）

油圧装置の設計システム群。全体計画は [../MASTER_PLAN.md](../MASTER_PLAN.md)。

| フォルダ | 内容 | 状態 |
|---|---|---|
| `cylinder/` | 油圧シリンダー設計（旧 hydraulic-designer）。目標 `docs/GOALS.md`、到達点 `docs/CHECKPOINTS.md` | CP1 済み。次は M1 自動選定 |
| `circuit/` | 油圧回路設計。アクチュエーター・弁・ポンプの構成と、圧力・流量の計算。油圧全体の上流。使い方と構成は `circuit/README.md` | 回路エディタと計算（流量・圧力・発熱・油温）、積層弁、印刷まで動く（2026-11-13）。`circuit/start.bat` で起動、ポート 5010 |
| `power-unit/` | 油圧ユニット設計。ポンプ・モーター・タンク・フィルター・クーラーの選定と配置 | 未着手 |
| `valve-stand/` | バルブスタンド設計。電磁弁・マニホールド・サブプレートの配置と架台 | 未着手 |
| `piping/` | 油圧配管設計（製図）。配管ルート・継手・配管図・部材表 | 未着手 |
| `shared/` | 油圧共通の標準（作動油、ポート・継手規格、シール、Oリング溝） | 未着手（今は `cylinder/standards/` にある） |

各システムは「インタビュー → GOALS.md → マイルストーン → チェックポイント」で進める。
